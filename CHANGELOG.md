## 1.0.0

* Initial release of `fan_deck_otp`.
* 2-stage animated playing card fan-and-stack collapse when code is completed.
* Rotating neon `SweepGradient` border loader with blur glow.
* Damped sine-wave horizontal shake animation with digit dissolve on error.
* Generalized support for any code length (4-digit PINs, 6-digit OTPs, etc.).
* `FanDeckOtpController` for programmatic control (`triggerError()`, `clear()`, `setValue()`).
* Comprehensive theming via `FanDeckOtpTheme`.
* Obscure text support for PIN authentication.
* Autofill, custom keyboard input formatters, and haptic feedback support.
